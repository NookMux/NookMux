---
title: Docker 部署
---

本文档提供直接使用 Docker 镜像运行 NookMux 的方法。生产环境仍推荐使用 [Docker Compose 部署](/cn/installation/deployment-methods/docker-compose-installation)，以便统一管理 Redis、日志和数据卷。

## 基本要求

- 已安装 Docker。
- 默认监听端口为 `3000`。
- 必须挂载 `/data` 目录保存 SQLite 数据库和上传/缓存数据。

## 使用 SQLite 运行

```shell
docker run --name nookmux -d --restart always \
  -p 3000:3000 \
  -e TZ=Asia/Shanghai \
  -e SESSION_SECRET=replace_with_a_random_string \
  -e CRYPTO_SECRET=replace_with_another_random_string \
  -v /your/data/path:/data \
  ghcr.io/nookmux/nookmux:latest
```

<Card type="warning" title="数据持久化">
  请将 `/your/data/path` 替换为真实主机目录，并确保容器有读写权限。未挂载 `/data` 会导致容器重建后数据丢失。
</Card>

## 使用外部 MySQL

```shell
docker run --name nookmux -d --restart always \
  -p 3000:3000 \
  -e SQL_DSN="mysql://user:password@db-host:3306/nookmux" \
  -e TZ=Asia/Shanghai \
  -e SESSION_SECRET=replace_with_a_random_string \
  -e CRYPTO_SECRET=replace_with_another_random_string \
  -v /your/data/path:/data \
  ghcr.io/nookmux/nookmux:latest
```

## 使用外部 PostgreSQL

```shell
docker run --name nookmux -d --restart always \
  -p 3000:3000 \
  -e SQL_DSN="postgres://user:password@db-host:5432/nookmux" \
  -e TZ=Asia/Shanghai \
  -e SESSION_SECRET=replace_with_a_random_string \
  -e CRYPTO_SECRET=replace_with_another_random_string \
  -v /your/data/path:/data \
  ghcr.io/nookmux/nookmux:latest
```

## 可选：连接 Redis

```shell
-e REDIS_CONN_STRING="redis://:password@redis-host:6379"
```

配置 Redis 后会启用跨节点缓存与同步能力；多节点部署时必须让所有节点使用同一 Redis 和相同的 `SESSION_SECRET` / `CRYPTO_SECRET`。

## 访问系统

部署完成后访问 `http://服务器IP:3000`，首次访问将进入初始化页面。完成初始化后即可使用创建的管理员账号登录。

<Card type="warning" title="首次初始化的安全窗口">
  初始化接口（`/api/setup`）在完成初始化之前匿名可达。新实例直接暴露公网时，外部访问者可能抢在您之前注册 root 管理员账号。请确保首次初始化在内网完成，或先通过防火墙/安全组限制对 `3000` 端口（尤其是 `/api/setup` 路径）的访问来源，初始化完成后再对外开放。初始化完成后该接口自动失效，重复调用 `/api/setup` 会被拒绝。
</Card>

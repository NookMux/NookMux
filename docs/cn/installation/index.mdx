## 概述

NookMux 是基于 Go 的 AI API 网关和管理后台，支持 Docker、Docker Compose、面板部署、集群部署和本地开发运行。生产环境推荐优先使用 Docker Compose，以便统一管理应用、Redis、数据目录和日志目录。

当前官方容器镜像为：`ghcr.io/nookmux/nookmux:latest`。

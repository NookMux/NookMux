## 核对基准

本页以当前仓库代码为准，核对范围仅限 `docs/zh/api/`：

- 路由：`internal/httpapi/router/api_router.go`、`internal/httpapi/router/relay_router.go`、`internal/httpapi/router/dashboard.go`
- 请求边界：`internal/httpapi/controller/`（按资源子包）
- AI 请求结构：`internal/domain/shared/`、`internal/relay/`
- 管理资源结构：`internal/model/`、`internal/config/`

本轮核对起点共有 **255** 条运行时 method/path；原中文生成页归一化后覆盖
**180** 条。机械集合差异为 **缺 99 条、旧 24 条**。其中动态路由
`/api/oauth/:provider`、`/v1/models/*path` 和 `/v1beta/models/*path` 会覆盖若干
具体 URL，因此不能只按字符串判断。

现有生成页引用的 `openapi/generated/**/*.json` 及生成脚本并不在本仓库中，无法在
这里重建其参数表。本页因此直接记录由当前 Go 代码确认的契约，并作为中文 API
文档的项目级覆盖层。

## 已确认不再支持

下列能力在当前项目中不可用，本轮已移除对应的 22 个中文接口页：

- 视频任务：`/v1/videos*`、`/v1/video/generations*`、`/kling/v1/videos*`、`/jimeng/`
- Creem：`POST /api/creem/webhook`、`POST /api/user/creem/pay`
- 旧倍率接口：`GET /api/ratio_config`、`GET /api/ratio_sync/channels`、`POST /api/ratio_sync/fetch`
- 旧安全状态：`GET /api/verify/status`
- 未注册 OAuth provider：Discord、OIDC、Telegram、WeChat

当前 OAuth 仅注册 `github`、`linuxdo`。其他 provider 即使命中
`GET /api/oauth/:provider`，也会返回“未知提供方”，不代表该能力可用。

## 原生成页缺少的运行时路由

以下为代码实际注册、但原中文生成页没有对应契约的 99 条路由。

### 系统、用户与认证

```text
GET    /api/rankings
GET    /api/user/checkin
POST   /api/user/checkin
GET    /api/user/self/usage_log_fields
PUT    /api/user/passkey/:id
DELETE /api/user/passkey/:id
POST   /api/user/epay/notify
GET    /api/oauth/:provider
POST   /api/oauth/email/bind
```

- `GET /api/rankings`：可选 query `period`，默认 `week`。
- `GET /api/user/checkin`：可选 query `month`，格式 `YYYY-MM`。
- `PUT /api/user/passkey/:id`：JSON body `{ "device_name": "..." }`。
- `POST /api/oauth/email/bind`：JSON body 必须含 `email`、`code`。
- OAuth 回调必须同时携带会话中签发的 `state` 和 provider 返回的 `code`。

### Root 系统设置

```text
GET    /api/option/value
GET    /api/option/json_map
PUT    /api/option/json_map
DELETE /api/option/json_map
GET    /api/option/json_array
PUT    /api/option/json_array
DELETE /api/option/json_array
GET    /api/option/channel_affinity_cache
DELETE /api/option/channel_affinity_cache
POST   /api/option/reset_tool_billing_rules
```

- `option/value`：query `key` 必填，敏感配置禁止读取。
- `option/json_map` 查询参数：`key`、`page`、`page_size`、`keyword`。
- JSON Map 写入 body：`key`、`map_key`、`old_map_key`、`value`；删除 body：
  `key`、`map_key`。
- `option/json_array` 仅保留旧 `minimax.voice_whitelist` 的兼容读取；PUT/DELETE
  会明确返回“已迁移到音色管理”，不能再作为成功写入接口使用。
- 清理亲和缓存需 query `all=true`，或提供 `rule_name`。

### 数据库迁移与性能

```text
GET    /api/db/pre_migrate/info
POST   /api/db/pre_migrate
GET    /api/db/pre_migrate/:id
GET    /api/db/same_type_migrate/info
POST   /api/db/same_type_migrate
GET    /api/db/same_type_migrate/:id
GET    /api/performance/stats
DELETE /api/performance/disk_cache
POST   /api/performance/reset_stats
POST   /api/performance/gc
```

两个迁移启动接口使用相同 JSON body：

```json
{
  "target_dsn": "目标业务库 DSN",
  "target_log_dsn": "目标日志库 DSN",
  "include_logs": true,
  "force": false
}
```

迁移接口均为 Root 权限；响应中的 `job_id` 用于查询 `/:id`。DSN 属于敏感信息，
不要写入日志或公开示例。

### 渠道扩展

```text
POST   /api/channel/test_proxy
POST   /api/channel/ollama/pull
POST   /api/channel/ollama/pull/stream
DELETE /api/channel/ollama/delete
GET    /api/channel/ollama/version/:id
GET    /api/channel/plan/quota/:id
GET    /api/channel/plan/glm/usage/:id
GET    /api/channel/plan/glm/risk/:id
```

- 代理测试 body：`{ "proxy": "http://host:port" }`；支持 `http`、`https`、
  `socks5`、`socks5h`。
- Ollama 拉取和删除 body：`channel_id`、`model_name`；流式拉取返回 SSE。
- GLM 用量 query：`type`（默认 `model`）、`startTime`、`endTime`；时间格式
  `YYYY-MM-DD HH:mm:ss`，范围不能超过 31 天。

### 令牌密钥

```text
POST /api/token/batch/keys
POST /api/token/:id/key
PUT  /api/token/:id/key
```

- 批量读取 body：`{ "ids": [1, 2] }`。
- 列表、搜索和详情接口只返回等长星号掩码；完整 key 只能通过上述专用接口读取。
- `PUT /api/token/:id/key` 会生成新 key，并立即使旧 key 失效。

### 工单

```text
GET  /api/ticket/
GET  /api/ticket/admin
POST /api/ticket/
GET  /api/ticket/:id
POST /api/ticket/:id/reply
POST /api/ticket/:id/close
POST /api/ticket/:id/status
```

- 列表 query：`p`、`page_size`、`status`（默认 `all`）、`keyword`。
- 创建 body：`title`、`type`、`content`。
- 回复 body：`content`；更新状态 body：`status`。
- 路由组要求 User 鉴权；管理员列表和状态操作仍会在业务层校验角色。

### 使用日志与审计日志

```text
GET    /api/log/
DELETE /api/log/
GET    /api/log/self
GET    /api/log/stat
GET    /api/log/self/stat
GET    /api/log/token
GET    /api/log/token/usage_log_fields
GET    /api/log/channel_affinity_usage_cache
GET    /api/audit/
GET    /api/audit/modules
```

使用日志通用筛选参数为：`p`、`page_size`、`type`、`start_timestamp`、
`end_timestamp`、`token_name`、`model_name`、`group`、`request_id`、
`upstream_request_id`、`ip`、`ua`、`x_title`、`http_referer`；管理员接口另支持
`username`、`channel`。普通用户不能用不可见字段做侧信道筛选。

审计日志 query：`p`、`page_size`（最大 100）、`username`、`module`、
`action_type`、`start_timestamp`、`end_timestamp`。

### 数据看板

```text
GET  /api/data/users
GET  /api/data/media_convert_stats
GET  /api/data/self/media_convert_stats
POST /api/data/recalculate
GET  /api/dashboard/config
PUT  /api/dashboard/config
POST /api/dashboard/config/reset
```

- 数据接口使用 `start_timestamp`、`end_timestamp`；重新计算要求二者都为正且
  `end_timestamp > start_timestamp`。
- Dashboard 更新 body 是字段到值的 JSON map。可写字段包括各面板开关、聚合开关、
  刷新间隔、时间范围和排行榜上限；字段名以 `DashboardConfig` 的 JSON 名称为准。

### 存储媒体

```text
GET    /api/stored_media/
GET    /api/stored_media/self
GET    /api/stored_media/:media_type/:id
DELETE /api/stored_media/:media_type/:id
POST   /api/stored_media/batch
```

- 列表 query：`p`、`page_size`、`start_timestamp`、`end_timestamp`。
- `media_type` 仅允许 `image` 或 `video`。
- 批量删除 body：`{ "items": [{ "id": "...", "media_type": "image" }] }`。
- 返回的 `/mcp/image/:id`、`/mcp/video/:id` URL 已带 `exp`、`sig`，有效期一小时；
  这两个签名资源路由不是可自行拼接的公开文件 API。

### 动态倍率

```text
GET    /api/dynamic_ratio/status
GET    /api/dynamic_ratio/rules
POST   /api/dynamic_ratio/rules
PUT    /api/dynamic_ratio/rules
DELETE /api/dynamic_ratio/rules/:id
PUT    /api/dynamic_ratio/rules/reorder
PUT    /api/dynamic_ratio/enabled
```

规则 body 字段：`id`（更新时必填）、`enable`、`group`、`models`、`concurrency`、
`weekdays`、`start_time`、`end_time`、`ratio`、`priority`。`models` 和 `weekdays`
是 JSON 数组字符串，时间格式为 `HH:MM`。重排 body 为 `{ "ids": [...] }`，
开关 body 为 `{ "enabled": true }`。用户状态接口可选 query `group`。

### 定制音色与音色管理

```text
GET    /api/custom_voice/tags
POST   /api/custom_voice/preview
POST   /api/custom_voice/confirm_quote
POST   /api/custom_voice/confirm
GET    /api/custom_voice/voices/
POST   /api/custom_voice/voices/
PUT    /api/custom_voice/voices/:id
DELETE /api/custom_voice/voices/:id
```

- 试听使用 `multipart/form-data`：`file`、`model`、`voice_id`、`text`、
  `need_noise_reduction`、`need_volume_normalization`。
- 报价和确认 body：`{ "voice_id": "..." }`。
- 音色列表 query：`page`、`page_size`、`type`、`operator_id`、`voice_id`、
  `start_timestamp`、`end_timestamp`。
- 音色创建/更新 body：`voice_id`、`type`、`redirect_id`、`allowed`、`remark`；
  `type` 仅允许 `preview`、`created`。

### AI、兼容与内部路由

```text
GET    /v1/models/:model
GET    /v1beta/openai/models
POST   /v1/responses/compact
POST   /v1/edits
POST   /v1/images/variations
DELETE /v1/models/:model
POST   /v1/models/*path
POST   /v1beta/models/*path
GET    /dashboard/billing/subscription
GET    /dashboard/billing/usage
GET    /v1/dashboard/billing/subscription
GET    /v1/dashboard/billing/usage
POST   /pg/chat/completions
GET    /mcp/image/:id
GET    /mcp/video/:id
```

- `GET /v1/models/:model` 获取单个模型；`/v1beta/openai/models` 是 Gemini OpenAI
  兼容模型列表。
- Responses compact body：`model`、`input`、`instructions`、
  `previous_response_id`。
- `/v1/edits` 是图像编辑兼容入口。
- `/v1/images/variations` 和 `DELETE /v1/models/:model` 当前明确返回“未实现”。
- 两个 `*path` 是 Gemini 动态 action 路由，实际 URL 形如
  `/v1beta/models/{model}:generateContent`。
- `/pg/chat/completions` 使用用户 Session，服务于内置 Playground，不使用 API Token。
- Billing 路由使用只读 API Token，响应兼容旧 OpenAI Dashboard 格式。

## 已有接口的参数变化

| 接口 | 当前契约变化 |
| --- | --- |
| `GET /api/user/search` | 除兼容的 `keyword`、`group` 外，新增 `username`、`display_name`、`email`、`linux_do_id`、`github_id`、`status`、`role`、`p`、`page_size`。 |
| `PUT /api/user/setting` | 当前字段为 `notify_type`、`quota_warning_threshold`、`webhook_url`、`webhook_secret`、`notification_email`、`bark_url`、`gotify_url`、`gotify_token`、`gotify_priority`。 |
| `GET /api/channel/` | 新增 `group` 过滤；保留 `p`、`page_size`、`id_sort`、`tag_mode`、`status`、`type`。 |
| `GET /api/channel/search` | 除 `keyword`、`group`、`model` 外，新增 `id`、`name`、`tag`、`status`、`type`、`id_sort`、`tag_mode`、`p`、`page_size`。 |
| `POST/PUT /api/token/` | 新增 `quota_type`、`window_hours`、`window_quota`、`window_start_hour`、`cycle_days`、`cycle_quota`；运行时统计字段不可由客户端设置。 |
| `GET /api/token/search` | 新增 `token`、`group`、`status`、`all`、`p`、`page_size`；`status` 为 1 启用、2 禁用、3 过期、4 额度耗尽。 |
| `POST/PUT /api/models/` | 新增 `context_length`、`max_output_tokens`、`input_modalities`、`output_modalities`、`capabilities`、`knowledge_cutoff`、`release_date`、`parameter_count`；`sync_official` 不再是 JSON API 字段。 |
| `POST/PUT /api/vendors/` | 新增可空字段 `data_retention_days`、`training_opt_out`。 |
| `POST /v1/chat/completions` | 当前 DTO 还接受 `verbosity`、`top_k`、`parallel_tool_calls`、`safety_identifier`、`store`、`prompt_cache_key`、`prompt_cache_retention`、`metadata`、`prediction` 及若干供应商扩展字段。 |
| `POST /v1/responses` | 新增 `include`、`metadata`、`parallel_tool_calls`、`top_logprobs`、`safety_identifier`、`service_tier`、`store`、`prompt_cache_key`、`prompt_cache_retention`、`text`、`user`、`max_tool_calls`、`prompt` 等字段；`instructions` 接受原始 JSON，而非仅限字符串。 |
| `POST /v1/messages` | 新增 `context_management`、`output_config`、`output_format`、`container`、`mcp_servers`、`service_tier` 等 Claude 字段。 |
| `POST /v1beta/models/{model}:generateContent` | 当前请求还支持 `safetySettings`、`tools`、`toolConfig`、`systemInstruction`、`cachedContent`，以及批量请求的 `requests`。 |
| `POST /v1/embeddings` | 除标准字段外，当前 DTO 还接受 `user`、`seed`、`temperature`、`top_p`、`frequency_penalty`、`presence_penalty`。 |
| `POST /v1/rerank` | 新增 `max_chunk_per_doc`、`overlap_tokens`。 |
| `POST /v1/audio/speech` | 新增 `instructions`、`stream_format`、`metadata`。 |
| `POST /v1/images/generations` | 当前是直接的 OpenAI 风格字段 `model`、`prompt`、`n`、`size`、`quality`、`response_format` 等，不再使用旧文档中的 `input` + `parameters` 包装。 |

AI 扩展字段是否会被转发还取决于目标渠道及参数过滤配置；“DTO 能解析”不等于每个上游都支持。

## 鉴权变化

- `GET /api/models` 需要 User 鉴权。
- `GET /api/channel/fetch_models/:id`、`POST /api/channel/fetch_models` 需要 Root 鉴权。
- `/api/option/*`、`/api/db/*`、`/api/performance/*` 均需要 Root 鉴权。
- Token 列表/详情不再返回明文 key；读取和重置 key 必须走专用接口。
- `GET /api/pricing`、`GET /api/rankings` 受对应 Header Nav 模块开关控制。

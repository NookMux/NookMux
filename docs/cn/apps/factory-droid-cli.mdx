## 安装

macOS / Linux：

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

Windows（PowerShell）：

```powershell
irm https://app.factory.ai/cli/windows | iex
```

安装后按提示把可执行文件目录加入 PATH。Droid CLI 要求登录官方账号（免费）后才能使用。

## 接入 NookMux

Droid CLI 通过 `~/.factory/settings.json` 的 `customModels` 数组配置自定义模型。NookMux 提供 OpenAI 兼容接口，示例如下：

```json
{
  "customModels": [
    {
      "model": "gpt-5.6",
      "displayName": "NookMux GPT",
      "baseUrl": "https://your-domain.com/v1",
      "apiKey": "${NOOKMUX_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 16384
    }
  ]
}
```

- `model`：与 NookMux 渠道中配置的模型名一致。
- `baseUrl`：NookMux 站点地址 + `/v1`。
- `apiKey`：支持 `${VAR_NAME}` 语法引用环境变量，例如先 `export NOOKMUX_API_KEY=sk-your-nookmux-token`；也可以直接写令牌字符串，但要注意文件权限。
- `provider`：
  - `generic-chat-completion-api`：OpenAI Chat Completions 兼容（大多数场景用这个）。
  - `openai`：OpenAI Responses API（用于 `gpt-5` / `gpt-5-codex` 等新模型）。
  - `anthropic`：Anthropic Messages API，此时 `baseUrl` 填 NookMux 站点根地址，`model` 用 `claude-*` 系列。

Anthropic 模型示例：

```json
{
  "customModels": [
    {
      "model": "claude-sonnet-4-5-20250929",
      "displayName": "NookMux Claude",
      "baseUrl": "https://your-domain.com",
      "apiKey": "${NOOKMUX_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 16384
    }
  ]
}
```

## 使用

1. 在 NookMux 控制台「密钥」页面创建令牌并复制完整 `sk-` 密钥。
2. 导出环境变量：

   ```bash
   export NOOKMUX_API_KEY=sk-your-nookmux-token
   ```

3. 启动 Droid CLI：

   ```bash
   cd /path/to/your/project
   droid
   ```

4. 使用 `/model` 命令，在 "Custom models" 分组中选择刚配置的模型。

## 常见问题

### 模型不出现在选择器

- 检查 `~/.factory/settings.json` 是否为合法 JSON。
- 确认 `model`、`baseUrl`、`provider` 等必填字段完整。

### 认证失败

- 确认环境变量已导出且与 `apiKey` 中的 `${...}` 引用名一致。
- 确认令牌是完整 `sk-` 开头的 NookMux 密钥且未被禁用。

### PowerShell 执行策略限制

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

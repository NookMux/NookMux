NookMux 基于上游开源项目和社区生态进行自用定制，感谢以下项目和社区的长期贡献。

## 上游项目

- **[newapi](https://github.com/QuantumNous/new-api)**：本项目的上游基础项目。
- **[One API](https://github.com/songquanpeng/one-api)**：newapi 上游基础之一。

## 参考与相关项目

- **[MicroWARP](https://github.com/ccbkkb/MicroWARP)**：Cloudflare WARP SOCKS5 Docker 代理方案。
- **[AxonHub](https://github.com/looplj/axonhub)**：AI API 网关参考实现。
- **[OpenAFW](https://github.com/openafw/openafw)**：本地 AI 流量安全过滤方案参考。
- **zaicontrol（私有仓库）**：Z.AI 套餐查询相关接口参考。
- **[cc-switch](https://github.com/farion1231/cc-switch)**：Kimi 套餐查询相关接口参考。

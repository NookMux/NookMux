---
title: 性能分析设置指南
---

NookMux 支持两类性能分析能力：

- **pprof**：临时诊断 Go 进程性能问题。
- **Pyroscope**：持续性能分析和火焰图可视化。

## pprof

设置环境变量：

```bash
ENABLE_PPROF=true
```

启用后，后端会启动独立调试服务器，监听 `0.0.0.0:8005`，pprof 路径为：

```text
http://<host>:8005/debug/pprof/
```

如果使用 Docker，需要额外暴露 `8005` 端口；默认 `docker-compose.yml` 只暴露应用端口 `3000`。

```yaml
ports:
  - "3000:3000"
  - "8005:8005"
```

## Pyroscope

配置 Pyroscope 服务地址即可启用：

```bash
PYROSCOPE_URL=http://localhost:4040
PYROSCOPE_APP_NAME=nookmux
PYROSCOPE_BASIC_AUTH_USER=your-user
PYROSCOPE_BASIC_AUTH_PASSWORD=your-password
PYROSCOPE_MUTEX_RATE=5
PYROSCOPE_BLOCK_RATE=5
HOSTNAME=your-hostname
```

说明：

- `PYROSCOPE_URL` 为空时不启动 Pyroscope。
- `PYROSCOPE_APP_NAME` 默认值为 `nookmux`。
- `PYROSCOPE_MUTEX_RATE` 和 `PYROSCOPE_BLOCK_RATE` 默认值为 `5`。
- `HOSTNAME` 可用于在 Pyroscope 中区分实例来源。

## 验证

Docker 用户可检查环境变量：

```bash
docker exec nookmux env | grep -E "PPROF|PYROSCOPE"
```

pprof 验证：

```bash
curl http://127.0.0.1:8005/debug/pprof/
```

Pyroscope 验证：打开 Pyroscope UI，查看 `PYROSCOPE_APP_NAME` 对应应用是否出现采样数据。

## 环境变量参考

| 变量                            | 必需 | 默认值    | 说明                  |
| ------------------------------- | ---- | --------- | --------------------- |
| `ENABLE_PPROF`                  | 否   | `false`   | 启用 pprof 调试服务器 |
| `PYROSCOPE_URL`                 | 否   | -         | Pyroscope 服务地址    |
| `PYROSCOPE_APP_NAME`            | 否   | `nookmux` | Pyroscope 应用标识    |
| `PYROSCOPE_BASIC_AUTH_USER`     | 否   | -         | Basic Auth 用户名     |
| `PYROSCOPE_BASIC_AUTH_PASSWORD` | 否   | -         | Basic Auth 密码       |
| `PYROSCOPE_MUTEX_RATE`          | 否   | `5`       | Mutex 采样率          |
| `PYROSCOPE_BLOCK_RATE`          | 否   | `5`       | Block 采样率          |
| `HOSTNAME`                      | 否   | -         | 实例标识              |

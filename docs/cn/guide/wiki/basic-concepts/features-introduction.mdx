title: 特性说明
---

以下特性按当前仓库实现核对，旧上游文档中的固定截图、旧菜单名称和 `/chat2link` 等入口不再作为当前项目事实。

## API 网关与上游渠道

- 统一代理 OpenAI、Anthropic、Gemini、Azure、AWS、OpenRouter、DeepSeek、Moonshot、智谱、MiniMax、Ollama、SiliconFlow、ByteDance、小米等渠道类型。
- 支持渠道分组、权重、优先级、标签聚合、批量管理、渠道测试和余额/套餐额度查询。
- 支持 Coding Plan 特殊 Base 标识，如 `glm-coding-plan`、`kimi-coding-plan`、`minimax-coding-plan`、`xiaomi-coding-plan` 等。
- 支持渠道参数覆盖，可按请求内容、模型、路径和内置变量动态调整请求体或 Header。

## 计费与额度

- 默认 `QuotaPerUnit = 500000`，即 1 美元对应 500,000 配额点数。
- 支持模型固定价格、模型倍率、补全倍率、分组倍率、分组间倍率覆盖和动态倍率。
- 支持缓存价格、音频价格、上下文分段价格、工具调用价格等更细粒度计费。
- 支持钱包充值、兑换码、邀请奖励、订单查询和可选订阅/支付能力。

## 控制台与运维

- React 19 + TypeScript + Rsbuild 管理后台。
- 侧边栏包含体验中心、常规、个人、支持、管理员等分区，可在系统设置中控制模块显示。
- 支持数据看板、API 密钥、使用日志、多模态文件、用户、渠道、模型、兑换码、动态倍率、审计日志等管理页面。
- 支持系统公告、FAQ、API 地址、Uptime Kuma 状态页和使用日志字段可见性配置。

## 身份、安全与审计

- 支持密码登录/注册、邮箱限制、GitHub/LinuxDo OAuth、Passkey、Turnstile 等身份能力。
- 用户个人资料页支持账号绑定、通知偏好、两步验证、访问令牌和安全设置。
- 支持模型请求速率限制、敏感词、SSRF 防护、审计日志。
- 管理员对系统资源的增删改会记录审计日志，便于追溯。

## 分析与性能

- 支持通过环境变量注入 Google Analytics 4 与 Umami 统计脚本。
- 支持 `ENABLE_PPROF=true` 启用 pprof 调试服务器。
- 支持 Pyroscope 持续性能分析。
- 支持磁盘缓存、性能监控阈值、日志清理和数据库维护工具。

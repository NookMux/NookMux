## 概述

NookMux 是基于 [newapi](https://github.com/QuantumNous/new-api) 的自用定制版 AI API 网关 / 代理项目。项目用于个人学习、研究与自用场景，提供统一 API 入口、渠道管理、计费、日志、用户和控制台管理能力。

当前仓库地址：[https://github.com/NookMux/NookMux](https://github.com/NookMux/NookMux)

## 项目定位

- 面向自托管和自用场景，不承诺稳定性、可用性或长期维护。
- 兼容常见 OpenAI 风格接口，并聚合多个上游模型服务。
- 提供管理后台，用于维护渠道、模型、API 密钥、用户、计费和审计日志。
- 项目基于上游 newapi 定制，不代表上游项目立场，也不保证与上游保持同步。

## 核心能力

- **统一入口**：通过统一 API 网关接入多个上游供应商。
- **渠道调度**：支持渠道分组、权重、优先级、重试、自动禁用/恢复和渠道亲和性。
- **计费管理**：支持模型价格、模型倍率、分组倍率、动态倍率、缓存/音频/工具调用价格和充值。
- **安全控制**：支持 API 密钥权限、模型访问控制、速率限制、敏感词、SSRF 防护和审计日志。
- **运营后台**：提供数据看板、使用日志、用户管理、兑换码、钱包、订单查询和系统设置。
- **多模态扩展**：支持图片、视频、音频、自定义音色和多模态文件资源管理等能力，具体取决于渠道与模型配置。

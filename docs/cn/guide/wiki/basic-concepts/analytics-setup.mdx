---
title: 分析工具设置指南
---

NookMux 支持通过环境变量为 Web 界面注入 Google Analytics 4 和 Umami 统计脚本。

相关实现位于 `main.go`：设置环境变量后，后端在前端静态页面中注入对应脚本。

## Google Analytics 4

1. 在 Google Analytics 中创建媒体资源和网站数据流。
2. 复制测量 ID，格式通常为 `G-XXXXXXXXXX`。
3. 配置环境变量：

```bash
GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
```

Docker Compose 示例：

```yaml
environment:
  - GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
```

## Umami

1. 在 Umami Cloud 或自托管 Umami 中创建网站。
2. 复制网站 ID。
3. 配置环境变量：

```bash
UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
UMAMI_SCRIPT_URL=https://analytics.umami.is/script.js
```

`UMAMI_SCRIPT_URL` 可选；未设置时默认使用 `https://analytics.umami.is/script.js`。

Docker Compose 示例：

```yaml
environment:
  - UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  - UMAMI_SCRIPT_URL=https://analytics.umami.is/script.js
```

## Docker Run 示例

```bash
docker run -d \
  -e GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX \
  -e UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx \
  ghcr.io/nookmux/nookmux:latest
```

## 验证

重启应用后：

1. 打开 Web 页面。
2. 打开浏览器开发者工具的 Network 面板。
3. 刷新页面并检查是否加载：
   - Google Analytics：`https://www.googletagmanager.com/gtag/js`
   - Umami：`UMAMI_SCRIPT_URL` 指向的脚本。

Docker 用户可检查容器环境变量：

```bash
docker exec nookmux env | grep -E "GOOGLE_ANALYTICS|UMAMI"
```

## 环境变量参考

| 变量                  | 必需 | 默认值                                 | 说明           |
| --------------------- | ---- | -------------------------------------- | -------------- |
| `GOOGLE_ANALYTICS_ID` | 否   | -                                      | GA4 测量 ID    |
| `UMAMI_WEBSITE_ID`    | 否   | -                                      | Umami 网站 ID  |
| `UMAMI_SCRIPT_URL`    | 否   | `https://analytics.umami.is/script.js` | Umami 脚本 URL |

---
title: 文档
---

顶部导航的 **文档** 入口由 **系统设置 → 站点与品牌 → 系统信息** 中的 `文档链接`（`general_setting.docs_link`）控制。

- 配置为空时，文档入口可能不可见或保持默认行为，取决于顶部导航模块配置。
- 配置为 URL 后，用户点击文档入口会跳转到该地址。
- 顶部导航模块本身可在 **系统设置 → 站点与品牌 → 顶部导航** 中启用或隐藏。

相关实现：`web/src/features/system-settings/general/system-info-section.tsx`、`web/src/features/system-settings/maintenance/config.ts`。

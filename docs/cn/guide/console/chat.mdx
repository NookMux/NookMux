---
title: 体验中心
---

当前控制台的体验中心不再维护旧文档中的 ChatGPT Next Web、Lobe Chat、AMA 问天、OpenCat 等固定外部应用说明。侧边栏的体验中心主要包含：

- **游乐园**：路由 `/playground`，用于在网页内快速测试提示词、模型、流式响应等。
- **多模态 → 自定义音色**：路由 `/multimodal/custom-voice`，用于 MiniMax 自定义音色相关能力（需管理员配置并启用）。

如果需要给用户提供外部聊天客户端配置入口，可在 **系统设置 → 站点与品牌 → 顶部导航** 和 **系统设置 → 控制台内容** 中配置导航与说明内容，或在 API 密钥页复制所需调用参数后手动填入客户端。

渠道页面入口为 `/channels`，用于管理上游供应商、密钥、分组、模型映射、权重、优先级、测试和参数覆盖。

## Coding Plan 套餐特殊渠道参数

如果使用内置 Coding Plan 套餐，`API 地址` 字段不要填写真实 URL，而是填写对应特殊标识。当前项目在 `internal/domain/channel/constant/channel.go` 的 `ChannelSpecialBases` 中内置以下标识：

| 套餐名称          | 渠道类型选择 | API 地址（填写标识）                |
| ----------------- | ------------ | ----------------------------------- |
| 智谱 GLM 官方套餐 | ZhipuV4      | `glm-coding-plan`                   |
| 智谱 GLM 国际套餐 | ZhipuV4      | `glm-coding-plan-international`     |
| Kimi 官方套餐     | Moonshot     | `kimi-coding-plan`                  |
| MiniMax 官方套餐  | MiniMax      | `minimax-coding-plan`               |
| MiniMax 国际套餐  | MiniMax      | `minimax-coding-plan-international` |
| Ollama 官方套餐   | Ollama       | `ollama-coding-plan`                |
| 小米国内套餐      | Xiaomi       | `xiaomi-coding-plan`                |
| 小米新加坡套餐    | Xiaomi       | `xiaomi-coding-plan-sgp`            |
| 小米荷兰套餐      | Xiaomi       | `xiaomi-coding-plan-ams`            |

套餐渠道创建后，可在渠道列表中查询套餐额度使用情况；当前支持的额度查询标识由 `SupportedPlanQuotaProviders` 定义。

智谱 GLM 套餐会按请求协议路由到不同上游：

| 协议                    | 官方套餐（国内）                              | 国际套餐                              |
| ----------------------- | --------------------------------------------- | ------------------------------------- |
| Anthropic Messages      | `https://open.bigmodel.cn/api/anthropic`      | `https://api.z.ai/api/anthropic`      |
| OpenAI Chat Completions | `https://open.bigmodel.cn/api/coding/paas/v4` | `https://api.z.ai/api/coding/paas/v4` |
| OpenAI Responses        | `https://open.bigmodel.cn/api/v1`             | `https://api.z.ai/api/v1`             |

## 参数覆盖

渠道参数覆盖支持简单 JSON 合并，也支持 `operations` 高级操作。常用操作包括：

- 字段操作：`set`、`delete`、`move`、`copy`
- 拼接与数组/对象合并：`append`、`prepend`
- 字符串规范化：`trim_prefix`、`trim_suffix`、`ensure_prefix`、`ensure_suffix`、`trim_space`、`to_lower`、`to_upper`
- 替换：`replace`、`regex_replace`
- 其他高级操作：`return_error`、`prune_objects`、`set_header`、`delete_header`、`copy_header`、`move_header`、`pass_headers`、`sync_fields`

条件判断支持 `full`、`prefix`、`suffix`、`contains`、`gt`、`gte`、`lt`、`lte`，并支持 `invert` 和 `pass_missing_key`。

示例：

```json
{
  "operations": [
    {
      "path": "model",
      "mode": "trim_prefix",
      "value": "openai/"
    },
    {
      "path": "temperature",
      "mode": "set",
      "value": 0.3,
      "conditions": [
        {
          "path": "messages.0.content",
          "mode": "contains",
          "value": "代码"
        }
      ]
    }
  ]
}
```

相关实现：`internal/relay/common/override.go`、`internal/domain/channel/constant/channel.go`。

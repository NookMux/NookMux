---
title: 多模态与图像视频
---

当前项目没有旧版独立“绘图设置”页面。图像、视频、音频和多模态能力由以下配置共同决定：

- **渠道**：对应上游供应商、API 地址、模型映射、参数覆盖和可用分组。
- **模型管理**：模型元数据、供应商、分类、可见性和部署配置。
- **系统设置 → 计费与支付 → 模型定价**：图像/视频/音频模型价格、按次计费或 token 计费规则。
- **系统设置 → 模型与路由**：Gemini、Claude、MiniMax 等模型族的专项配置。
- **多模态文件**：管理自动转 URL 场景下的图片/视频资源。

因此，文生图、图生图、视频生成等能力应按具体渠道和模型分别配置。

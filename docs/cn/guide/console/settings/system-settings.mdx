---
title: 系统设置总览
---

当前 NookMux 的系统设置入口为 `/system-settings/site`。进入后侧边栏会切换成“系统管理”视图，并按功能拆成 7 个分组：

| 分组       | 路由前缀                      | 说明                                                                                           |
| ---------- | ----------------------------- | ---------------------------------------------------------------------------------------------- |
| 站点与品牌 | `/system-settings/site`       | 系统名称、服务器地址、文档链接、Logo、关于、首页内容、用户协议、隐私政策、顶部导航、侧边栏模块 |
| 身份验证   | `/system-settings/auth`       | 密码登录/注册、邮箱限制、OAuth、Passkey、Turnstile                                             |
| 计费与支付 | `/system-settings/billing`    | 新用户额度、充值、支付、模型定价、分组定价、签到奖励                                           |
| 模型与路由 | `/system-settings/models`     | 全局模型设置、Gemini、Claude、Grok、MiniMax、渠道亲和性                                        |
| 安全与限制 | `/system-settings/security`   | 速率限制、敏感词、SSRF 防护、审计日志                                                          |
| 控制台内容 | `/system-settings/content`    | 数据看板、公告、API 地址、FAQ、Uptime Kuma、使用日志字段                                       |
| 运维       | `/system-settings/operations` | 系统行为、监控告警、SMTP、Worker、日志维护、数据库维护、性能、更新检查                         |

旧文档中的“系统设置 / 模型相关设置 / 倍率设置 / 速率限制设置 / 数据看板 / 聊天设置 / 绘图设置 / 支付设置 / 运营设置 / 其它设置”已不再是当前页面结构。

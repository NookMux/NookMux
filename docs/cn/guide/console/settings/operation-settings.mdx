---
title: 运维
---

旧文档中的“运营设置”现在主要拆到 **系统设置 → 运维** 与 **系统设置 → 计费与支付**。

运维分组包含：

- **系统行为**：自动重试、重试状态码、默认折叠侧边栏等。
- **监控与警报**：渠道响应时间阈值、额度提醒阈值、自动禁用/恢复渠道、定时渠道测试。
- **SMTP 邮箱**：邮件服务器配置。
- **Worker 代理**：Worker URL、校验 Key、是否允许 HTTP 图片请求。
- **日志维护**：消费/错误/充值/管理/系统日志清理。
- **数据库维护**：数据库迁移与同步。
- **性能**：磁盘缓存、性能监控阈值。
- **维护**：版本/更新检查等维护工具。

充值、支付、签到、额度和倍率相关配置请到 **计费与支付** 分组。

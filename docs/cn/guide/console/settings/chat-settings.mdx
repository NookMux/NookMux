---
title: 聊天与导航
---

当前项目没有旧版独立“聊天设置”页面。与聊天/体验入口相关的配置分散在以下位置：

- **系统设置 → 站点与品牌 → 顶部导航**：控制首页、控制台、Key 查询、定价、排行榜、文档、关于等顶部导航入口。
- **系统设置 → 站点与品牌 → 侧边栏模块**：控制游乐园、自定义音色等体验中心入口是否展示。
- **API 密钥页**：用户复制 API 地址、密钥和模型信息后，可手动配置到兼容 OpenAI API 的聊天客户端。
- **游乐园**：内置网页测试入口，路由 `/playground`。

如果需要维护固定聊天客户端链接，应优先使用当前控制台内容/导航配置能力，而不是依赖旧版一键导入截图。

当前支付配置位于 **系统设置 → 计费与支付 → 支付设置**。

## 支付设置

常用字段：

- `TopUpLink`：外部充值链接。
- `PayAddress`、`EpayId`、`EpayKey`：易支付风格网关配置。
- `PayMethods`：前端展示的充值方式 JSON。
- `payment_setting.amount_options`：预设充值金额。
- `payment_setting.amount_discount`：按充值金额设置折扣。
- `StripeApiSecret`、`StripeWebhookSecret`、`StripePriceId`、`StripeUnitPrice`、`StripeMinTopUp`、`StripePromotionCodesEnabled`：Stripe 配置。

`PayMethods` 示例：

```json
[
  {
    "name": "支付宝",
    "color": "#1677ff",
    "type": "alipay"
  },
  {
    "name": "微信",
    "color": "#07C160",
    "type": "wxpay"
  },
  {
    "name": "Stripe",
    "color": "#635bff",
    "type": "stripe",
    "min_topup": "50"
  }
]
```

字段说明：

- `name`：支付方式展示名称。
- `color`：按钮或徽标颜色，支持 CSS 颜色值。
- `type`：支付通道标识；`stripe` 走 Stripe，其余常见值走易支付风格网关，具体支持取决于后端控制器和已启用的支付模块。
- `min_topup`：该支付方式最低充值金额。

相关实现：`internal/httpapi/controller/topup/topup.go`、`internal/httpapi/controller/topup/topup_stripe.go`、`web/src/features/system-settings/integrations/payment-settings-section.tsx`。

## 渠道

### 新增渠道集成（Vercel / GMI Cloud / VyceAI / Modal / Kilo）

单批新增 5 个渠道（编号 66~70）：Vercel AI Gateway 复用 OpenAI 类型支持 Chat/Responses 端点；GMI Cloud 附带音频/音乐异步任务与批量推理扩展；VyceAI 将生图请求转为上游 SSE 流并聚合为同步响应；Modal 按渠道配置间隔对每个模型发真实推理请求保活；Kilo 支持免密钥匿名调用免费模型并按 `isFree` 同步免费模型列表。

### AgnesAI 文本、图片与视频整合

AgnesAI 升级为全模态渠道：文本 adaptor 透传 OpenAI / Claude / Responses 三种格式，图片参数归一（size / ratio / return_base64），视频任务统一校验并新增「模型映射后、预扣费前」校验钩子，任务查询复用 CAS 持久化与退款结算路径。

- eccfd97f-feat: complete Agnes text image and video integration

### 批量删除渠道

新增按 ID 区间与按精确名称两个批量删除接口：区间先取实际存在 ID 防稀疏误删，名称先加锁再在应用层精确比较防排序规则误判，事务分块删除并级联清理 abilities。

- 998f4b5a-feat: bulk delete channels by ID range or exact name

## 用户与风控

### 定时封禁与自动解封

用户禁用支持时长语义（截止时间以 Unix 秒落库规避三库差异），后台任务批量到期解封、鉴权路径惰性解封；用户管理、批量操作、连锁封禁、GitHub 年龄风控等入口全链路支持禁用时长，封禁提示附解禁时间。

- 632d1b52-feat: support timed user bans and automatic unban

### 全站用户批量操作

新增全站用户批量管理接口：启用全部已禁用、禁用全部已启用（必填原因）、软删除、永久删除、清理已注销用户五种动作，事务分块执行并失效缓存、写审计；前端提供批量操作下拉与确认弹窗。

- 0c80da7d-feat: add global user batch operations

### 密码强度与强制设密

新增登录密码强度策略（≥8 字符且含数字/大小写/符号），纯 OAuth 账号强制引导设置登录密码，新增专用改密接口并从资料更新接口移除 legacy 改密通道，杜绝借道改密。

- 4db618c1-feat: require login password setup and enforce password strength
- 8d7ee9a2-fix: remove legacy self-service password changes

### 注册与邀请体系（域名邮箱豁免 / 邮箱消歧 / 16 位邀请码）

已验证域名邮箱可按白名单豁免邀请码与注册码（黑名单优先、支持通配，后拆分为两个独立豁免列表并自动迁移旧配置）；邮箱比较大小写归一、多用户命中时返回歧义错误而非擅自选定；邀请码强制升级为 16 位无混淆字母表并幂等迁移存量用户。

- 85781f43-feat: support domain email code-free registration
- 14a24193-fix: split email domain registration code exemptions
- 8807b946-feat: Enhance email identity handling with case insensitivity and ambiguity checks
- 6fcfc9b2-feat: enforce 16-character invite codes

- d727441b-feat: support negative model pricing with save confirmation

## 监控与日志

### 模型状态服务端定时刷新与短时间窗口

公开状态接口改为只读进程内快照（访客请求不再触发日志扫描），后台任务按配置间隔重算快照；时间窗口新增 0.5h / 1h / 6h / 12h 短窗口，统计槽位最小限制放宽至 1 分钟。

- 4fc34076-feat: add short time windows to model status
- 0c4cb469-fix: refresh model status on a server schedule

### 渠道测试上游响应模型回显

渠道测试捕获上游实际响应体并提取 `model` 字段回显，便于核对模型重定向 / 映射是否生效。

从最终上游请求体提取显式思考强度（多协议 gjson 路径），随日志落库并在用量日志以 Tag 展示；只记录不推断。

---
title: Environment Variable Configuration Guide
---

This document lists common NookMux environment variables and their defaults. The complete list is defined in `.env.example` at the repository root, and the backend parsing logic lives in `internal/app/env.go`, `internal/infra/redis/redis.go`, `internal/store/db/migrate/`, and related files.

<Card type="info" title="Tip">
  NookMux can read environment variables from the project root `.env` file. Copy `.env.example` to `.env` and adjust it as needed. Unset variables use the defaults shown below.
</Card>

## Basic Configuration

| Environment Variable | Description | Default Value | Example |
| --- | --- | --- | --- |
| `PORT` | Service listening port, also available via the `--port` startup flag | `3000` | `PORT=8080` |
| `TZ` | Time zone | - | `TZ=Asia/Shanghai` |
| `VERSION` | Override the running version number, which defaults to the build-time git commit | Build value | `VERSION=1.2.3` |
| `GIN_MODE` | Gin runtime mode; set it to `release` to disable debug logs | - | `GIN_MODE=release` |
| `FRONTEND_BASE_URL` | Only effective on slave nodes; non-API routes are redirected to this address | - | `FRONTEND_BASE_URL=https://your-domain.com` |

## Real Client IP (Reverse Proxy / CDN)

| Environment Variable | Description | Default Value |
| --- | --- | --- |
| `TRUSTED_PROXIES` | Comma-separated list of trusted proxy IPs/CIDRs. Headers such as `CF-Connecting-IP` and `X-Forwarded-For` are only parsed when the request comes from a trusted proxy. Special values: `private`/`local`, `cloudflare`/`cf`, `all`/`unsafe`, `none`/`disable` | `private,cloudflare` |

## Database Configuration

| Environment Variable | Description | Default Value | Example |
| --- | --- | --- | --- |
| `SQL_DSN` | Database connection string; it must start with `mysql://`, `postgres://` or `postgresql://` — any other prefix fails at startup; SQLite is used when unset | SQLite (`data/one-api.db`) | MySQL: `SQL_DSN=mysql://user:password@127.0.0.1:3306/dbname`; PostgreSQL: `SQL_DSN=postgres://user:password@127.0.0.1:5432/dbname` |
| `LOG_SQL_DSN` | Separate database connection string for log tables; leave empty to share the main database | - | `LOG_SQL_DSN=mysql://user:password@127.0.0.1:3306/logs` |
| `SQLITE_PATH` | SQLite database file path | `data/one-api.db` | `SQLITE_PATH=/var/lib/nookmux/nookmux.db` |
| `SQL_MAX_IDLE_CONNS` | Maximum number of idle connections in the pool | `20` | `SQL_MAX_IDLE_CONNS=50` |
| `SQL_MAX_OPEN_CONNS` | Maximum number of open connections in the pool | `1000` | `SQL_MAX_OPEN_CONNS=500` |
| `SQL_MAX_LIFETIME` | Maximum connection lifetime (seconds) | `60` | `SQL_MAX_LIFETIME=120` |
| `SQL_PREPARE_STMT` | Enable GORM prepared statement cache for hot SQL paths | `false` | `SQL_PREPARE_STMT=true` |

</Info>

## Multi-Node and Security Configuration

| Environment Variable | Description | Default Value | Example |
| --- | --- | --- | --- |
| `SESSION_SECRET` | Session secret. It must be set for multi-node deployments and must be identical on every node. If set to `random_string`, startup fails immediately. | - | `SESSION_SECRET=<random>` |
| `COOKIE_SECURE` | Whether the session cookie carries the `Secure` flag (sent only over HTTPS). Must be enabled for HTTPS deployments (or when a reverse proxy terminates TLS), otherwise the long-lived session cookie may leak over plaintext HTTP channels | `false` | `COOKIE_SECURE=true` |
| `CRYPTO_SECRET` | Encryption secret used to encrypt sensitive database content. If unset, it reuses `SESSION_SECRET` | `SESSION_SECRET` | `CRYPTO_SECRET=<random>` |
| `NODE_TYPE` | Node type. Nodes set to `slave` skip database migrations, root account creation, and scheduled channel checks | `master` | `NODE_TYPE=slave` |

<Card type="warning" title="RELAY_TIMEOUT warning">
  Be careful when setting `RELAY_TIMEOUT`: a too-short timeout can let the upstream API finish and bill successfully while the local side times out before billing completes, causing billing desynchronization. Keep the default `0` unless you know exactly why you are changing it.
</Card>

## Deprecated / Removed Environment Variables

The following variables are no longer read by the current code, but they are kept here to avoid misconfiguration:

| Environment Variable | Status |
| --- | --- |
| `UPDATE_TASK` | Removed; async task updates are controlled by the system scheduler |
| `ENABLE_METRIC`, `METRIC_QUEUE_SIZE`, `METRIC_SUCCESS_RATE_THRESHOLD` | Removed; channel auto-disable and related features are controlled by monitoring settings in System Settings |
| `TEST_PROMPT` | Removed; test prompts are controlled by System Settings |
| `TASK_PRICE_PATCH` | Removed; use the multiplier settings in System Settings for task pricing |
| `REDIS_MASTER_NAME`, `REDIS_CONN_POOL_SIZE`, `REDIS_PASSWORD` | Removed; Redis configuration is now controlled through the `REDIS_CONN_STRING` connection string and variables such as `REDIS_POOL_SIZE` |
| `GEMINI_MODEL_MAP`, `GEMINI_SAFETY_SETTING` | Deprecated; configure them in System Settings -> Model Settings |

## Multi-Machine Deployment Example

### Master Node Configuration

```bash
# Database configuration - use an external database
SQL_DSN=postgres://user:password@db-server:5432/nookmux

# Security configuration
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis cache configuration
REDIS_CONN_STRING=redis://:password@redis-server:6379
```

### Slave Node Configuration

```bash
# Database configuration - use the same remote database
SQL_DSN=postgres://user:password@db-server:5432/nookmux

# Security configuration - use the same secrets as the master node
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis cache configuration - use the same Redis instance as the master node
REDIS_CONN_STRING=redis://:password@redis-server:6379

# Node type setting
NODE_TYPE=slave

# Frontend base URL, only effective on slave nodes
FRONTEND_BASE_URL=https://your-domain.com
```

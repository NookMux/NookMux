## Overview

NookMux is a Go-based AI API gateway and admin console. It supports Docker, Docker Compose, panel deployments, cluster deployments, and local development. For production, Docker Compose is recommended so you can manage the app, Redis, data directory, and logs in one place.

The current official container image is `ghcr.io/nookmux/nookmux:latest`.

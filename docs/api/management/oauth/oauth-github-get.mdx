🔓 No Authentication Required (OAuth Callback)

The actual runtime route is handled by the generic `GET /api/oauth/{provider}` endpoint, with `provider=github` here. You must provide the `state` generated by `GET /api/oauth/state` and stored in the same session, together with the `code` returned by GitHub. If `state` is missing or does not match the session, the request returns `403`.

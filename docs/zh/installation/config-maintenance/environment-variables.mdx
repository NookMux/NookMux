---
title: 环境变量配置指南
---

本文档列出 NookMux 常用环境变量及默认值。完整清单以仓库根目录的 `.env.example` 为准，后端解析逻辑见 `internal/app/env.go`、`internal/infra/redis/redis.go`、`internal/store/db/migrate/` 等。

<Callout type="info" title="提示">
  NookMux 支持从项目根目录的 `.env` 文件读取环境变量。可复制 `.env.example` 为 `.env` 后按需修改；未设置的变量使用下表默认值。
</Callout>

## 基本配置

| 环境变量 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| `PORT` | 服务监听端口（也可用 `--port` 启动参数） | `3000` | `PORT=8080` |
| `TZ` | 时区设置 | - | `TZ=Asia/Shanghai` |
| `VERSION` | 覆盖运行版本号（默认为编译时注入的 git commit） | 编译值 | `VERSION=1.2.3` |
| `GIN_MODE` | Gin 运行模式，设为 `release` 关闭调试日志 | - | `GIN_MODE=release` |
| `FRONTEND_BASE_URL` | 仅从节点生效；设置后非 API 路由重定向到该地址 | - | `FRONTEND_BASE_URL=https://your-domain.com` |

## 真实客户端 IP（反向代理 / CDN）

| 环境变量 | 说明 | 默认值 |
| --- | --- | --- |
| `TRUSTED_PROXIES` | 逗号分隔的可信代理 IP/CIDR 列表；仅当请求来自可信代理时才解析 `CF-Connecting-IP`、`X-Forwarded-For` 等头。特殊值：`private`/`local`、`cloudflare`/`cf`、`all`/`unsafe`、`none`/`disable` | `private,cloudflare` |

## 数据库配置

| 环境变量 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| `SQL_DSN` | 数据库连接字符串，必须以 `mysql://`、`postgres://` 或 `postgresql://` 开头，其他前缀启动时报错；不设置使用 SQLite | SQLite（`data/one-api.db`） | MySQL: `SQL_DSN=mysql://user:password@127.0.0.1:3306/dbname`；PostgreSQL: `SQL_DSN=postgres://user:password@127.0.0.1:5432/dbname` |
| `LOG_SQL_DSN` | 日志表独立数据库连接字符串，留空与主库共用 | - | `LOG_SQL_DSN=mysql://user:password@127.0.0.1:3306/logs` |
| `SQLITE_PATH` | SQLite 数据库文件路径 | `data/one-api.db` | `SQLITE_PATH=/var/lib/nookmux/nookmux.db` |
| `SQL_MAX_IDLE_CONNS` | 空闲连接池最大连接数 | `20` | `SQL_MAX_IDLE_CONNS=50` |
| `SQL_MAX_OPEN_CONNS` | 连接池最大打开连接数 | `1000` | `SQL_MAX_OPEN_CONNS=500` |
| `SQL_MAX_LIFETIME` | 连接最大生命周期（秒） | `60` | `SQL_MAX_LIFETIME=120` |
| `SQL_PREPARE_STMT` | 启用 GORM 预编译语句缓存（高频 SQL 路径可开启） | `false` | `SQL_PREPARE_STMT=true` |

## 缓存与 Redis 配置

| 环境变量 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| `REDIS_CONN_STRING` | Redis 连接字符串；不设置则禁用 Redis | -（禁用） | `REDIS_CONN_STRING=redis://:password@localhost:6379/0` |
| `REDIS_POOL_SIZE` | Redis 连接池大小 | `50` | `REDIS_POOL_SIZE=20` |
| `REDIS_MIN_IDLE_CONNS` | Redis 最小空闲连接数 | `5` | `REDIS_MIN_IDLE_CONNS=2` |
| `REDIS_DIAL_TIMEOUT` | Redis 连接超时（秒） | `5` | - |
| `REDIS_READ_TIMEOUT` | Redis 读超时（秒） | `3` | - |
| `REDIS_WRITE_TIMEOUT` | Redis 写超时（秒） | `3` | - |
| `REDIS_MAX_RETRIES` | Redis 命令重试次数 | `3` | - |
| `MEMORY_CACHE_ENABLED` | 是否启用进程内存缓存 | `false` | `MEMORY_CACHE_ENABLED=true` |
| `SYNC_FREQUENCY` | 缓存与数据库同步频率（秒） | `60` | `SYNC_FREQUENCY=60` |
| `BATCH_UPDATE_ENABLED` | 是否启用数据库批量更新聚合 | `false` | `BATCH_UPDATE_ENABLED=true` |
| `BATCH_UPDATE_INTERVAL` | 批量更新聚合时间间隔（秒） | `5` | `BATCH_UPDATE_INTERVAL=10` |

<Callout type="info">
  配置 `REDIS_CONN_STRING` 后会自动启用内存缓存（兼容旧行为）。
</Callout>

## 多节点与安全配置

| 环境变量 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| `SESSION_SECRET` | 会话密钥；多机部署必须设置且所有节点一致。设为 `random_string` 时启动会直接失败 | - | `SESSION_SECRET=<random>` |
| `COOKIE_SECURE` | 会话 cookie 是否附加 `Secure` 标记（仅经 HTTPS 传输）。HTTPS 部署（或反向代理终止 TLS）必须开启，否则长期会话 cookie 可能经明文 HTTP 信道泄露 | `false` | `COOKIE_SECURE=true` |
| `CRYPTO_SECRET` | 加密密钥（加密数据库敏感内容）；不设置时复用 `SESSION_SECRET` | `SESSION_SECRET` | `CRYPTO_SECRET=<random>` |
| `NODE_TYPE` | 节点类型；设为 `slave` 的节点跳过数据库迁移、根账号创建和定时渠道测试 | `master` | `NODE_TYPE=slave` |

<Callout type="info" title="集群部署">
  关于如何使用这些环境变量构建完整的集群部署，请参考[集群部署指南](/zh/docs/installation/deployment-methods/cluster-deployment)。
</Callout>

<Callout type="warn" title="RELAY_TIMEOUT 设置警告">
  设置 `RELAY_TIMEOUT` 时请谨慎：过短的超时可能导致上游 API 已完成请求并计费，但本地因超时未完成计费，造成计费不同步。建议保持默认 `0`，除非您知道自己在做什么。
</Callout>

## 多机部署示例

### 主节点配置

```bash
# 数据库配置 - 使用外部数据库
SQL_DSN=postgres://user:password@db-server:5432/nookmux

# 安全配置
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis 缓存配置
REDIS_CONN_STRING=redis://:password@redis-server:6379
```

### 从节点配置

```bash
# 数据库配置 - 使用相同的远程数据库
SQL_DSN=postgres://user:password@db-server:5432/nookmux

# 安全配置 - 与主节点使用相同的密钥
SESSION_SECRET=your_unique_session_secret
CRYPTO_SECRET=your_unique_crypto_secret

# Redis 缓存配置 - 与主节点使用相同的 Redis
REDIS_CONN_STRING=redis://:password@redis-server:6379

# 节点类型设置
NODE_TYPE=slave

# 前端基础 URL（仅从节点生效）
FRONTEND_BASE_URL=https://your-domain.com
```

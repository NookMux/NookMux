<Info>
  LangBot is an open-source instant messaging bot development platform that supports Feishu, DingTalk, WeChat, QQ, Telegram, Discord, Slack, and more. It integrates mainstream global AI models, supports knowledge bases, Agent, and MCP capabilities, and can connect to NookMux through an OpenAI-compatible interface.

## Connect to NookMux

LangBot supports connecting to locally deployed NookMux or any OpenAI-compatible NookMux service.

### Usage

1. Obtain an API key from NookMux.
   ![Get API key](/assets/langbot/get_api_key.png)

   If NookMux is deployed locally, configure the API address yourself (see [Container Network Connection](https://docs.langbot.app/en/workshop/network-details.html)). If you are using a third-party NookMux service, you can copy the address from the page. Note that `/v1` must be appended to the address.

2. Add a model in LangBot, select NookMux as the provider, and fill in the corresponding API key and API address.
   ![Add NookMux model](/assets/langbot/add_newapi_model.png)

3. Select the model to use in the pipeline.

   ![Choose model](/assets/langbot/select_model.png)

4. Use it in conversation debugging or by chatting with a bot bound to the pipeline.

   ![Chat](/assets/langbot/debug_chat.png)

   ![WeChat chat](/assets/langbot/wechat.png)

   For deployment and bot configuration, see [Deploying Bots](https://docs.langbot.app/en/deploy/platforms/readme.html).

### Using LangBot Knowledge Base

LangBot supports using NookMux embedding models as vector models for the knowledge base.

1. Add an embedding model in LangBot and select NookMux as the provider.
   ![Add embedding model](/assets/langbot/add_embedding_model.png)

2. Select the embedding model when creating a new knowledge base.
   ![Use embedding model](/assets/langbot/use_embedding_model.png)

For more usage instructions, see the [LangBot official documentation](https://docs.langbot.app/en/README.html).

## Integration

Cherry Studio connects to NookMux through an OpenAI-compatible interface.

### Parameters

| Item | Value |
| --- | --- |
| Provider Type | OpenAI / OpenAI-compatible |
| API Key | NookMux token (`sk-` prefix), created and copied from the "Keys" page |
| API Address | NookMux site address + `/v1`, for example `https://your-domain.com/v1` |
| Model | Add it manually or pull the model list from the API |

### Configuration Steps

1. Create a token on the NookMux console's "Keys" page and copy the API key.
2. Open Cherry Studio's "Settings" -> "Model Services" and add an OpenAI provider.
3. Fill in the API address `https://your-domain.com/v1` and the API key.
4. Add the models you want to use; the model names must match the model names configured in the NookMux channel.
5. Return to the chat page and start a conversation with the new model.

## Drawing

If your channel includes image generation models such as DALL·E or Gemini image models, select the matching model on Cherry Studio's drawing page. The setup is the same as for chat models.

## More Usage

Knowledge base and smart assistant features use the same provider setup and can all point to the same NookMux provider. For more details, see the [Cherry Studio official documentation](https://docs.cherry-ai.com).

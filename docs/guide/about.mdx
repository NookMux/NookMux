title: About
---

The top navigation **About** page is controlled by the `About` field in **System Settings -> Site and Brand -> System Information**.

- Leave it blank: show the default project description and the `NookMux/NookMux` repository link.
- Set a URL: the page opens the address in an embedded iframe.
- Set HTML: render the content as HTML.
- Set any other text: render it as Markdown.

Related implementation: `web/src/features/about/index.tsx`.

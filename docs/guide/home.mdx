---
title: Home
---

NookMux's home page defaults to a public landing page. Administrators can override it by setting `Home Content` in **System Settings -> Site and Brand -> System Information**.

- Leave it blank: show the built-in home page, including product intro, stats, features, and footer.
- Set Markdown/HTML: render custom content.
- Set a URL starting with `http://` or `https://`: load it in an embedded iframe.

Related implementation: `web/src/features/home/index.tsx`, `web/src/features/system-settings/general/system-info-section.tsx`.

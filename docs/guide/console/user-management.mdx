---
title: User Management
---

The `/users` page is used by administrators to view and maintain registered users.

Common actions include:

- View user status, role, balance, quota used, and registration info.
- Adjust user quota, group, status, and admin privileges.
- Check usage and top-up activity.

User management changes are system resource changes and are already audited on the backend; use **Audit Logs** to trace administrator actions.

---
title: Audit Logs
---

The `/audit-logs` route is used to view create, update, and delete operations performed by administrators on system resources.

The current project records audit logs for management actions on channels, users, tokens, redemption codes, models, vendors, dynamic ratios, and system settings.

Administrators can control this in **System Settings → Security & Limits → Audit Logs**:

- Whether audit logging is enabled.
- Which modules are recorded.
- Whether IP is recorded.
- Whether diffs are recorded.

Audit logs are for tracing management actions, not API usage logs.

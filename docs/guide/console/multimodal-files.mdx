---
title: Multimodal Files
---

The `/multimodal-files` route is used to manage uploaded images, videos, and other multimodal assets.

These assets mainly support the auto-to-URL / hosted-resource flow when text-only models call multimodal understanding tools. Pool size, upload limits, and cleanup policies are controlled jointly by environment variables and system settings.

Common environment variables:

- `MAX_IMAGE_UPLOAD_MB`
- `MAX_VIDEO_UPLOAD_MB`
- `STORED_IMAGE_POOL_MB`
- `STORED_VIDEO_POOL_MB`

Admins should set reasonable limits based on disk space and business risk.

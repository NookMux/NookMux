---
title: Data Dashboard
---

The console dashboard has two main entry points:

- `/dashboard/overview`: overview of instance usage, trends, and key metrics.
- `/dashboard/models`: model dashboard for usage, cost, and ranking data.

Visibility and dashboard content are controlled by:

- **System Settings → Console Content → Data Dashboard**: export, refresh interval, and default time range.
- **System Settings → Console Content → Dashboard Configuration**: dashboard panels.
- **System Settings → Site & Branding → Sidebar Modules**: whether console sidebar modules are shown.

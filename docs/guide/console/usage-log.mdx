---
title: Usage Logs
---

The `/usage-logs/common` route is used to view API calls, tasks, errors, refunds, and billing records.

- Regular users: view their own usage logs.
- Administrators: view all logs and filter by user, channel, model, token, or group.
- Log field visibility: configured in **System Settings → Console Content → Usage Log Fields**.

Related implementation: `web/src/features/usage-logs/`, `internal/config/console/config.go`.

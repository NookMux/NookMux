---
title: Multimodal and Image/Video
---

The current project has no old standalone "drawing settings" page. Image, video, audio, and multimodal capabilities are determined jointly by these settings:

- **Channels**: upstream providers, API address, model mapping, parameter overrides, and available groups.
- **Model Management**: model metadata, vendor, category, visibility, and deployment config.
- **System Settings → Billing & Payments → Model Pricing**: image, video, and audio model pricing, plus per-call or token-based billing rules.
- **System Settings → Models & Routing**: specialized settings for Gemini, Claude, MiniMax, and other model families.
- **Multimodal Files**: image and video assets managed for auto-to-URL scenarios.

Text-to-image, image-to-image, and video generation should be configured per channel and model.

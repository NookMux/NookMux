The old "Other Settings" page now mainly corresponds to **System Settings → Site & Branding**.

## System Information

Configurable items include:

- System name `SystemName`
- Server address `ServerAddress`
- Docs link `general_setting.docs_link`
- Logo URL
- Footer text
- About page content
- Home page content
- Terms of Service and Privacy Policy

Home and About content support Markdown and HTML. If a URL is entered, it is loaded in an iframe.

## Top Navigation

You can control whether entries such as Home, Console, Key Lookup, Pricing, Leaderboard, Docs, and About are shown. Pricing and Leaderboard can also require login.

## Sidebar Modules

You can control whether console sidebar modules are shown, including entries under Experience Center, General, Personal, Support, and Admin.

Related implementation: `web/src/features/system-settings/site/section-registry.tsx`, `web/src/features/system-settings/maintenance/config.ts`.

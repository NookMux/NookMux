Current payment configuration lives under **System Settings → Billing & Payments → Payment Settings**.

## Payment Settings

Common fields:

- `TopUpLink`: external top-up link.
- `PayAddress`, `EpayId`, `EpayKey`: EPay-style gateway configuration.
- `PayMethods`: JSON for the top-up methods shown in the frontend.
- `payment_setting.amount_options`: preset top-up amounts.
- `payment_setting.amount_discount`: discounts by top-up amount.
- `StripeApiSecret`, `StripeWebhookSecret`, `StripePriceId`, `StripeUnitPrice`, `StripeMinTopUp`, `StripePromotionCodesEnabled`: Stripe settings.

`PayMethods` example:

```json
[
  {
    "name": "Alipay",
    "color": "#1677ff",
    "type": "alipay"
  },
  {
    "name": "WeChat",
    "color": "#07C160",
    "type": "wxpay"
  },
  {
    "name": "Stripe",
    "color": "#635bff",
    "type": "stripe",
    "min_topup": "50"
  }
]
```

Field notes:

- `name`: display name for the payment method.
- `color`: button or badge color; any CSS color value is supported.
- `type`: payment channel identifier; `stripe` uses Stripe, while other common values use the EPay-style gateway, depending on backend support and enabled payment modules.
- `min_topup`: minimum top-up amount for that payment method.

Related implementation: `internal/httpapi/controller/topup/topup.go`, `internal/httpapi/controller/topup/topup_stripe.go`, `web/src/features/system-settings/integrations/payment-settings-section.tsx`.

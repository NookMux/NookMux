---
title: Operations
---

The old "Operations Settings" page is now split mainly between **System Settings → Operations** and **System Settings → Billing & Payments**.

The Operations group includes:

- **System Behavior**: auto retry, retry status codes, default collapsed sidebar, and similar behavior settings.
- **Monitoring and Alerts**: channel response thresholds, quota alert thresholds, auto-disable or restore channels, and scheduled channel tests.
- **SMTP Mail**: mail server configuration.
- **Worker Proxy**: Worker URL, verification key, and whether HTTP image requests are allowed.
- **Log Maintenance**: cleanup for consumption, error, top-up, admin, and system logs.
- **Database Maintenance**: migration and sync tools.
- **Performance**: disk cache and performance monitoring thresholds.
- **Maintenance**: version and update checks.

Top-up, payment, check-in, quota, and ratio settings belong under **Billing & Payments**.

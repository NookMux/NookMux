---
title: System Settings Overview
---

The current NookMux system settings entry is `/system-settings/site`. After entering it, the sidebar switches to a "System Management" view and is split into 7 groups:

| Group | Route Prefix | Description |
| --- | --- | --- |
| Site & Branding | `/system-settings/site` | System name, server address, docs link, logo, about page, home page, terms, privacy policy, top navigation, sidebar modules |
| Authentication | `/system-settings/auth` | Password login and registration, email restrictions, OAuth, Passkey, Turnstile |
| Billing & Payments | `/system-settings/billing` | New user quota, top-ups, payments, model pricing, group pricing, check-in rewards |
| Models & Routing | `/system-settings/models` | Global model settings, Gemini, Claude, Grok, MiniMax, channel affinity |
| Security & Limits | `/system-settings/security` | Rate limiting, sensitive words, SSRF protection, audit logs |
| Console Content | `/system-settings/content` | Data dashboard, announcements, API address, FAQ, Uptime Kuma, usage log fields |
| Operations | `/system-settings/operations` | System behavior, monitoring alerts, SMTP, Worker, log maintenance, database maintenance, performance, update checks |

The old "System Settings / Model-Related Settings / Ratio Settings / Rate Limit Settings / Data Dashboard / Chat Settings / Drawing Settings / Payment Settings / Operations Settings / Other Settings" pages are no longer the current structure.

---
title: Chat & Navigation
---

The current project has no old standalone chat settings page. Chat and experience-entry configuration is spread across these locations:

- **System Settings → Site & Branding → Top Navigation**: controls top navigation entries such as Home, Console, Key Lookup, Pricing, Leaderboard, Docs, and About.
- **System Settings → Site & Branding → Sidebar Modules**: controls whether Playground, Custom Voice, and other experience-center entries are shown.
- **API Keys** page: users can copy the API address, key, and model information, then manually configure a compatible OpenAI API chat client.
- **Playground**: built-in web testing entry, route `/playground`.

If you need to maintain fixed chat client links, prefer the current console content and navigation settings instead of relying on old one-click import screenshots.

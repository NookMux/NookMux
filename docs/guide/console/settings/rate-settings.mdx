title: Pricing Ratios

The old "Ratio Settings" page is now split under **System Settings → Billing & Payments**:

- **Model Pricing**: model prices, model ratios, completion ratios, cache pricing, audio pricing, context split pricing, and tool call pricing.
- **Group Pricing**: group ratios, recharge group ratios, user-selectable groups, auto groups, and group-ratio overrides.

## Quota Unit

The current backend default is `QuotaPerUnit = 500000`, which means 1 USD corresponds to 500,000 quota points. This can be changed through the `QuotaPerUnit` system option.

## Common Billing Formula

Token-based billing:

```text
quota consumption ≈ (input tokens + output tokens × completion ratio) × model ratio × group ratio
```

Per-call billing:

```text
quota consumption ≈ fixed model price × group ratio × QuotaPerUnit
```

Actual billing may also be affected by cache pricing, audio tokens, context split pricing, tool call pricing, dynamic ratios, subscription policies, and violation charges. The usage log is the source of truth.

## Missing Price or Ratio

If a model has no price or ratio configured, commercial use may return a "price not configured" error. Administrators should fill in the model configuration under Model Pricing.

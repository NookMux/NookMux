---
title: Security & Limits
---

The old "Rate Limit Settings" page is now under **System Settings → Security & Limits → Rate Limit**.

Configurable items include:

- Whether model request rate limiting is enabled.
- Maximum requests per limit window.
- Maximum successful requests per limit window.
- Limit window length in minutes.
- Group-based rate limit overrides.

Group rate limit example:

```json
{
  "default": [200, 100],
  "vip": [0, 1000]
}
```

The exact meaning within the same group follows the current page field descriptions. The Security & Limits group also includes sensitive words, SSRF protection, and audit log settings.

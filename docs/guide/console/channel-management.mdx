The `/channels` page is used to manage upstream providers, keys, groups, model mappings, weights, priorities, testing, and parameter overrides.

## Special Channel Parameters for Coding Plan Packages

If you use a built-in Coding Plan package, the `API Address` field must use the corresponding special identifier instead of a real URL. These identifiers are built into `internal/domain/channel/constant/channel.go` in `ChannelSpecialBases`.

| Package Name | Channel Type | API Address (Identifier) |
| --- | --- | --- |
| Zhipu GLM Official Plan | ZhipuV4 | `glm-coding-plan` |
| Zhipu GLM International Plan | ZhipuV4 | `glm-coding-plan-international` |
| Kimi Official Plan | Moonshot | `kimi-coding-plan` |
| MiniMax Official Plan | MiniMax | `minimax-coding-plan` |
| MiniMax International Plan | MiniMax | `minimax-coding-plan-international` |
| Ollama Official Plan | Ollama | `ollama-coding-plan` |
| Xiaomi China Plan | Xiaomi | `xiaomi-coding-plan` |
| Xiaomi Singapore Plan | Xiaomi | `xiaomi-coding-plan-sgp` |
| Xiaomi Netherlands Plan | Xiaomi | `xiaomi-coding-plan-ams` |

After a plan channel is created, quota usage can be queried from the channel list; the supported identifiers are defined by `SupportedPlanQuotaProviders`.

Zhipu GLM plans route requests to different upstreams based on protocol:

| Protocol | Official Plan (CN) | International Plan |
| --- | --- | --- |
| Anthropic Messages | `https://open.bigmodel.cn/api/anthropic` | `https://api.z.ai/api/anthropic` |
| OpenAI Chat Completions | `https://open.bigmodel.cn/api/coding/paas/v4` | `https://api.z.ai/api/coding/paas/v4` |
| OpenAI Responses | `https://open.bigmodel.cn/api/v1` | `https://api.z.ai/api/v1` |

## Parameter Overrides

The override system supports simple JSON merging and the advanced `operations` mode. Common operations include:

- Field operations: `set`, `delete`, `move`, `copy`
- Concatenation and array/object merging: `append`, `prepend`
- String normalization: `trim_prefix`, `trim_suffix`, `ensure_prefix`, `ensure_suffix`, `trim_space`, `to_lower`, `to_upper`
- Replacement: `replace`, `regex_replace`
- Other advanced operations: `return_error`, `prune_objects`, `set_header`, `delete_header`, `copy_header`, `move_header`, `pass_headers`, `sync_fields`

Conditions support `full`, `prefix`, `suffix`, `contains`, `gt`, `gte`, `lt`, `lte`, plus `invert` and `pass_missing_key`.

Example:

```json
{
  "operations": [
    {
      "path": "model",
      "mode": "trim_prefix",
      "value": "openai/"
    },
    {
      "path": "temperature",
      "mode": "set",
      "value": 0.3,
      "conditions": [
        {
          "path": "messages.0.content",
          "mode": "contains",
          "value": "代码"
        }
      ]
    }
  ]
}
```

Related implementation: `internal/relay/common/override.go`, `internal/domain/channel/constant/channel.go`.

---
title: Profile
---

The `/profile` page is used to manage account information, security settings, and notification preferences.

Main areas:

- **Profile Info**: view account basics, balance, usage, and more.
- **Account Bindings**: bind enabled email, WeChat, GitHub, Discord, OIDC, Telegram, LinuxDo, or custom OAuth accounts.
- **Security Settings**: change password, manage access tokens, two-factor authentication, Passkey, and account deletion.
- **Notification Settings**: configure balance alert thresholds and notification channels. Supported channels currently include `email`, `webhook`, `bark`, and `gotify`.
- **Check-in Calendar**: if enabled by the administrator, view check-in status and rewards.
- **Language Preference**: switch the current frontend language.

Available bindings and security features depend on what administrators enable in **System Settings → Authentication**.

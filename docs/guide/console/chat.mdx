---
title: Experience Center
---

The console's experience center no longer maintains the old documentation for fixed external apps such as ChatGPT Next Web, Lobe Chat, AMA 问天, or OpenCat. The current sidebar experience center mainly includes:

- **Playground**: route `/playground`, for quick prompt, model, and streaming tests in the browser.
- **Multimodal → Custom Voice**: route `/multimodal/custom-voice`, for MiniMax custom voice features (requires admin configuration and enablement).

If you need to provide users with external chat client setup entry points, configure navigation and explanatory content in **System Settings → Site & Branding → Top Navigation** and **System Settings → Console Content**, or copy the required parameters from the API Keys page and enter them manually in the client.

---
title: Pricing
---

The public pricing page shows the current instance's public model catalog and price information. It is available from the top navigation **Pricing** or the `/pricing` route.

Pricing data comes from model metadata, model prices, model ratios, and group ratios. Administrators can manage it in:

- **System Settings -> Billing & Payments -> Model Pricing**: model prices, ratios, context segment prices, and tool call prices.
- **System Settings -> Billing & Payments -> Group Pricing**: group ratios, auto groups, and optional groups.
- **Model Management**: model metadata, provider info, visibility, and deployment settings.

If the instance enforces restrictions such as "login required to view models/pricing", follow the current access policy.

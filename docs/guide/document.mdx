---
title: Documentation
---

The top navigation **Documentation** entry is controlled by the `Docs Link` (`general_setting.docs_link`) field in **System Settings -> Site and Brand -> System Information**.

- If left blank, the documentation entry may be hidden or keep its default behavior, depending on the top navigation configuration.
- If set to a URL, clicking the documentation entry redirects there.
- The top navigation module itself can be enabled or hidden in **System Settings -> Site and Brand -> Top Navigation**.

Related implementation: `web/src/features/system-settings/general/system-info-section.tsx`, `web/src/features/system-settings/maintenance/config.ts`.

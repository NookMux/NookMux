NookMux is a self-customized internal-use fork based on upstream open-source projects and the surrounding community ecosystem. Thanks to the following projects and communities for their long-term contributions.

## Upstream Projects

- **[newapi](https://github.com/QuantumNous/new-api)**: the upstream base project of this repository.
- **[One API](https://github.com/songquanpeng/one-api)**: one of the upstream foundations of newapi.

## Reference and Related Projects

- **[MicroWARP](https://github.com/ccbkkb/MicroWARP)**: a Cloudflare WARP SOCKS5 Docker proxy solution.
- **[AxonHub](https://github.com/looplj/axonhub)**: a reference implementation of an AI API gateway.
- **[OpenAFW](https://github.com/openafw/openafw)**: a reference for local AI traffic security filtering.
- **zaicontrol (private repository)**: reference for Z.AI plan lookup APIs.
- **[cc-switch](https://github.com/farion1231/cc-switch)**: reference for Kimi plan lookup APIs.

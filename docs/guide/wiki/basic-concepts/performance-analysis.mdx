---
title: Performance Analysis Setup Guide
---

NookMux supports two kinds of performance analysis:

- **pprof**: for temporary diagnosis of Go process performance issues.
- **Pyroscope**: for continuous profiling and flame graph visualization.

## pprof

Set the environment variable:

```bash
ENABLE_PPROF=true
```

When enabled, the backend starts a separate debug server listening on `0.0.0.0:8005`, and the pprof endpoint is:

```text
http://<host>:8005/debug/pprof/
```

If you use Docker, you must also expose port `8005`; the default `docker-compose.yml` only exposes application port `3000`.

```yaml
ports:
  - "3000:3000"
  - "8005:8005"
```

## Pyroscope

Set the Pyroscope service address to enable it:

```bash
PYROSCOPE_URL=http://localhost:4040
PYROSCOPE_APP_NAME=nookmux
PYROSCOPE_BASIC_AUTH_USER=your-user
PYROSCOPE_BASIC_AUTH_PASSWORD=your-password
PYROSCOPE_MUTEX_RATE=5
PYROSCOPE_BLOCK_RATE=5
HOSTNAME=your-hostname
```

Notes:

- Pyroscope will not start if `PYROSCOPE_URL` is empty.
- The default value of `PYROSCOPE_APP_NAME` is `nookmux`.
- The default values of `PYROSCOPE_MUTEX_RATE` and `PYROSCOPE_BLOCK_RATE` are `5`.
- `HOSTNAME` can be used to distinguish instances in Pyroscope.

## Verification

Docker users can check the environment variables:

```bash
docker exec nookmux env | grep -E "PPROF|PYROSCOPE"
```

pprof verification:

```bash
curl http://127.0.0.1:8005/debug/pprof/
```

Pyroscope verification: open the Pyroscope UI and check whether samples appear for the `PYROSCOPE_APP_NAME` application.

## Environment Variable Reference

| Variable                            | Required | Default Value | Description                   |
| ----------------------------------- | -------- | ------------- | ----------------------------- |
| `ENABLE_PPROF`                      | No       | `false`       | Enable the pprof debug server |
| `PYROSCOPE_URL`                     | No       | -             | Pyroscope service address     |
| `PYROSCOPE_APP_NAME`                | No       | `nookmux`     | Pyroscope application identifier |
| `PYROSCOPE_BASIC_AUTH_USER`         | No       | -             | Basic Auth username           |
| `PYROSCOPE_BASIC_AUTH_PASSWORD`     | No       | -             | Basic Auth password           |
| `PYROSCOPE_MUTEX_RATE`              | No       | `5`           | Mutex sampling rate           |
| `PYROSCOPE_BLOCK_RATE`              | No       | `5`           | Block sampling rate           |
| `HOSTNAME`                          | No       | -             | Instance identifier           |

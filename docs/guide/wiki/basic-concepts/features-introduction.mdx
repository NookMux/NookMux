title: Feature Description
---

The features below are verified against the current repository implementation. Static screenshots, legacy menu names, and entry points such as `/chat2link` from the old upstream docs are no longer treated as facts for this project.

## API Gateway and Upstream Channels

- Unified proxy support for OpenAI, Anthropic, Gemini, Azure, AWS, OpenRouter, DeepSeek, Moonshot, Zhipu, MiniMax, Ollama, SiliconFlow, ByteDance, Xiaomi, and more.
- Channel groups, weights, priorities, tag aggregation, bulk management, channel tests, and balance/plan quota lookup are supported.
- Special Coding Plan base identifiers are supported, such as `glm-coding-plan`, `kimi-coding-plan`, `minimax-coding-plan`, and `xiaomi-coding-plan`.
- Channel parameter overrides can adjust request bodies or headers dynamically based on request content, model, path, and built-in variables.

## Billing and Quotas

- The default `QuotaPerUnit` is `500000`, meaning 1 USD equals 500,000 quota points.
- Fixed model pricing, model ratios, completion ratios, group ratios, inter-group ratio overrides, and dynamic ratios are supported.
- Finer-grained billing is available for cache pricing, audio pricing, context segment pricing, and tool call pricing.
- Wallet top-ups, redemption codes, referral rewards, order lookup, and optional subscription/payment support are available.

## Console and Operations

- React 19 + TypeScript + Rsbuild admin console.
- The sidebar includes Experience, General, Personal, Support, and Admin sections, with module visibility controlled in system settings.
- Dashboard, API keys, usage logs, multimodal files, users, channels, models, redemption codes, dynamic ratios, and audit logs are all managed in the console.
- System announcements, FAQ, API address, Uptime Kuma status page, and usage-log field visibility can be configured.

## Identity, Security, and Auditing

- Password login/registration, email restrictions, GitHub/LinuxDo OAuth, Passkey, and Turnstile are supported.
- The profile page supports account linking, notification preferences, two-factor authentication, access tokens, and security settings.
- Model request rate limits, sensitive words, SSRF protection, and audit logs are supported.
- CRUD changes to system resources by administrators are recorded in audit logs for traceability.

## Analytics and Performance

- Google Analytics 4 and Umami tracking scripts can be injected through environment variables.
- `ENABLE_PPROF=true` enables the pprof debug server.
- Pyroscope continuous profiling is supported.
- Disk cache, performance monitoring thresholds, log cleanup, and database maintenance tools are supported.

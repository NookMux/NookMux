---
title: Analytics Tool Setup Guide
---

NookMux supports injecting Google Analytics 4 and Umami tracking scripts into the web UI through environment variables.

The related implementation lives in `main.go`: after the variables are set, the backend injects the corresponding scripts into the frontend static pages.

## Google Analytics 4

1. Create a property and web data stream in Google Analytics.
2. Copy the Measurement ID, usually in the format `G-XXXXXXXXXX`.
3. Configure the environment variable:

```bash
GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
```

Docker Compose example:

```yaml
environment:
  - GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX
```

## Umami

1. Create a site in Umami Cloud or a self-hosted Umami instance.
2. Copy the site ID.
3. Configure the environment variables:

```bash
UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
UMAMI_SCRIPT_URL=https://analytics.umami.is/script.js
```

`UMAMI_SCRIPT_URL` is optional; if it is not set, the default is `https://analytics.umami.is/script.js`.

Docker Compose example:

```yaml
environment:
  - UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  - UMAMI_SCRIPT_URL=https://analytics.umami.is/script.js
```

## Docker Run Example

```bash
docker run -d \
  -e GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX \
  -e UMAMI_WEBSITE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx \
  ghcr.io/nookmux/nookmux:latest
```

## Verification

After restarting the app:

1. Open the web page.
2. Open the browser DevTools Network panel.
3. Refresh the page and check for:
   - Google Analytics: `https://www.googletagmanager.com/gtag/js`
   - Umami: the script pointed to by `UMAMI_SCRIPT_URL`.

Docker users can check container environment variables:

```bash
docker exec nookmux env | grep -E "GOOGLE_ANALYTICS|UMAMI"
```

## Environment Variable Reference

| Variable              | Required | Default Value                          | Description        |
| --------------------- | -------- | -------------------------------------- | ------------------ |
| `GOOGLE_ANALYTICS_ID` | No       | -                                      | GA4 Measurement ID |
| `UMAMI_WEBSITE_ID`    | No       | -                                      | Umami Site ID      |
| `UMAMI_SCRIPT_URL`    | No       | `https://analytics.umami.is/script.js` | Umami script URL   |

## Overview

NookMux is a self-customized AI API gateway/proxy project based on [newapi](https://github.com/QuantumNous/new-api). It is intended for personal learning, research, and self-use, and provides a unified API entry, channel management, billing, logs, user management, and console management.

Current repository: [https://github.com/NookMux/NookMux](https://github.com/NookMux/NookMux)

## Project Positioning

- Built for self-hosted and self-use scenarios, with no promise of stability, availability, or long-term maintenance.
- Compatible with common OpenAI-style APIs and aggregates multiple upstream model providers.
- Includes an admin console for managing channels, models, API keys, users, billing, and audit logs.
- Based on upstream newapi customization and does not represent the upstream project's position or guarantee sync with upstream.

## Core Capabilities

- **Unified Entry**: Connect to multiple upstream providers through a single API gateway.
- **Channel Scheduling**: Supports channel groups, weights, priorities, retries, automatic disable/recovery, and channel affinity.
- **Billing Management**: Supports model pricing, model ratios, group ratios, dynamic ratios, cache/audio/tool-call pricing, and top-ups.
- **Security Control**: Supports API key permissions, model access control, rate limits, sensitive words, SSRF protection, and audit logs.
- **Operations Console**: Provides dashboards, usage logs, user management, redemption codes, wallet, order lookup, and system settings.
- **Multimodal Extensions**: Supports images, video, audio, custom voices, and multimodal file resource management, depending on channel and model configuration.
